# relate — cross-repo edges, only where evidence shows them

> phase 6. `evidence-over-verdict`, `what-can-be-rewritten` live in `spec.md §0.1`.

## the two types — and ONLY these two
    alternative-to    A positions itself as a substitute for B ("a X alternative", "unlike X",
                      "instead of X", "successor to X")
    conflicts-with    contradictory claims, or a stated incompatibility

## the gate
    no quote → NO relation. "no relation" is VALID and COMMON.
    the target must RESOLVE to a repo IN the collection — a quote naming an outside project
    (Puppeteer, SuperCollider, Rewind.ai) is recorded in the gist but is NOT a collection edge.
    never invent an edge to fill a slot (the `#void` discipline, applied to edges).
    never coin a NEW relation-type alone — surface a genuine third type to the user.

## compare QUALITIES, never quantities
    claims · features · dependencies · technologies. NEVER stars, dates, counts.

## deps are NOT edges
    a dependency is origin-truth — a `#git` fact, not a `#graph` edge.

## method (harvest-then-resolve — a build-time concretion, scales flat)
    phase 3 harvested relation-quotes into each gist's `#graph` (unresolved).
    phase 6 collects them, resolves targets against the collection, compiles `graph.md`,
    then mirrors each surviving edge back into its gists so the index reads standalone.
