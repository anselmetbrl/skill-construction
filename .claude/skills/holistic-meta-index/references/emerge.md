# emerge — a spoken companion that helps digest the index

> phase 8. `signal-over-saturation`, `void-over-hallucination`, `orientation-not-substitution`
> live in `spec.md §0.1`.

## what it is / is not
    IS       a post-scriptum beside the index — the whole SPOKEN, to help you digest it.
    IS NOT   a second index · NOT a self-audit · NOT a summary of each repo.

## form — TTS, for the eye AND the ear
    linear and speakable · no tables, no nesting that doesn't read aloud · **bold** the
    fields · atomic paragraph-modules, never walls.

## content — ONLY what EMERGED from the whole
    cross-cutting signals · the shape of the collection · warnings worth carrying into the
    reading — things that CANNOT sit in a single per-repo cell.

## gate
    non-redundant with the index · NON-padded — if little emerged, say LESS. never
    manufacture insight for length (the `#void` discipline, in prose).
