# self-check — one gate, two objects, two grains

> the gate the pipeline runs on ITSELF before it trusts anything it emits.
> the impartiality this pipeline demands of repos is run on the agent FIRST.
> this file is the portable home of the gate (`spec §2`, ledger `S3.6`): an installed
> skill runs in repos with no `CLAUDE.md`, so the gate must travel with the skill.

---

## the gate — four tests

read your own draft, and every artifact this pipeline emits, as an ADVERSARY:

    concrete-referent   does it NAME a practice / a piece of evidence — or does it only
                        SOUND like insight? a sentence that names nothing is slop.
    live-once           is this signal already carried elsewhere? then CUT it here.
                        duplication is bloat, not emphasis.
    provenance          an unconfirmed coinage stays a MARKED guess, never reused as
                        fact. a label you minted is not yet a shared object.
    cadence-suspicion   sounds profound (X-as-Y, meta-meta, grand nouns like
                        "altitudes / trinity / immune-system")? suspect it FIRST.
                        the closure-cadence is where hollow phrasing hides.

> run it once, fast, then act — do not spiral. the user catches the rest.

---

## two objects — the SAME gate applies to both

    the agent's prose      your own sentences to the user
    every artifact         dossier · gist · tag · relation · index · emerge

why one gate: the same four tests catch a superlative in a README and a superlative in
your own sentence. splitting them into two lists would duplicate a signal (`live-once`).

---

## two grains — WHEN the gate fires

    micro   after each PASS   — per-repo, per-batch, per-unit self-evaluation
    macro   before and after each PHASE — an entry check and an exit check

    NOT during   an llm cannot meaningfully self-monitor mid-generation. naming that
                 honestly beats specifying a check that never runs. the gate fires at
                 boundaries, not inside a generation.

---

## on failure

    self-heal   fix in place, OR revert that unit under git and try again.
    stay visible   the failure AND its resolution both remain — annotate, never delete
                   the shadow. a silently-smoothed defect is the one failure that cannot
                   be audited.

---

## when this gate itself misleads   [evolve]

    moderation    the check becomes a ritual that always passes — a rubber stamp.
    modification  audit against a SAMPLE the user picks, not one the agent picks.
