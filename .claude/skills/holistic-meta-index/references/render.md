# render — mechanical compiles from rulings + gists

> no judgment enters here. INDEX and EMERGE re-render what was ruled and grounded;
> a layout change never reprocesses content. anything not ruled renders as its
> default or #void — never quietly decided at render-time.

## INDEX.md

    head      run-id · the standing query · order provenance ("order: the user's,
              ruled <date>" or "order: seed order") · the void-legend with reasons
    legend    the ruled tag set, one line each, so the TOC is the bird's-eye ·
              flag legend ("flags are evidence — the user weighs them")
    list      FLAT · ruled order · each repo exactly ONCE · blocked repos IN,
              flagged, links preserved

    per entry:
        ## NN · owner/repo — official description (verbatim)
        glance   lang-roles · stars · contribs · update-cue · voids — FACTS ONLY;
                 counts exist HERE and nowhere else (C4)
        tags     the ruled tags, one dedicated line, ALWAYS visible — text-search
                 is the regrouping mechanism (search a tag, get its cluster)
        #git     origin-truth: license · forks · issues · release · dates · deps ·
                 DEEP links (readme anchors · docs · site · wiki), voids flagged
        #gist    the grounded claim ← "span" (link) lines, carried over as ruled
        #graph   ruled edges only, each with its quote+link · else exactly `#void`

    gates     standalone: zero pointers into run files (C5) — the index must be
              sufficient alone, on the user's machine, in an ide, greppable.
              no ranking prose, no cluster narration, no "notably" — arrangement
              speaks; commentary is what the session already ruled on.

## EMERGE.md

    source    ONLY observations the user ACCEPTED at the session — nothing else
              exists to say. little accepted → say less. none → EMERGE is three
              honest lines saying so.
    form      TTS prose — linear, speakable · **bold** the load-bearing words ·
              atomic paragraph-modules, never walls · no tables, no nesting that
              cannot be read aloud · no counts (C4) · subject = the repos and the
              collection, never the user (C8)
    job       help the user DIGEST the index they co-produced — the shape of the
              whole, the warnings worth carrying into the reading. not a second
              index. not a self-audit. not a narration of the run.

## after

    re-run all checks on both artifacts · fix visibly · commit · then phase 7:
    the user picks the audit sample and the run closes on THEIR reading, not on
    the counts.
