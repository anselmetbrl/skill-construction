# tag — few, distinctive, derived from the whole

> phase 5. `signal-over-saturation` and `void-over-hallucination` live in `spec.md §0.1`.

## caps
    4 per repo · ≤12 across the WHOLE collection · `lowercase_underscore`
    the union of all repos' tags must be ≤12 distinct tags. a tag SPENDS a slot.

## order
    derive per repo FIRST · distil the ≤12 AFTER every repo is tagged — discrimination
    is a property of the SET, not the repo. never reduce to 4 before tags converge.

## quality — NON-REDUNDANCY that PARTITIONS
    fails    redundant with a field       `rust` — lang-roles carries it
             a systemic given             `local` — assumed / near-universal here
             too broad to partition       `ai` (the whole index is ai) · `memory`
    passes   a distinctive FUNCTION that partitions the collection —
             an ACT (browser_automation, screen_capture, nix_configuration), not a
             category-label (a label absorbs the collection; an act divides it)

## form (from vocabulary.md — a GENERATOR, not a whitelist)
    prefer an act-noun that names what the repo DOES to/for the stack. the grammar
    shapes the form; it never supplies the list. never pick a tag BECAUSE it is in the
    vocabulary — pick what partitions.

## empty & pressure
    never force a tag → `#void`. a repo that fits none of the 12 is an OUTLIER — a finding.
    if 4 cannot carry a repo, or 12 cannot carry the collection, SURFACE the pressure to
    the user (candidate extra tags), do not conform at the cost of meaning.
