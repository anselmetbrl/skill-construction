## how-it-is · technology (internal)

    the definition given is by NEGATION first, then by a list of what it is "closer to"
      ← "WFGY 5.0 Polaris Protocol is not another AI writing preset. It is not a static
         persona toy. It is not a prompt pack dressed up as a product."
         (https://raw.githubusercontent.com/onestardao/WFGY/HEAD/README.md)
    the one component with stated mechanics is a goal compiler, described as seven steps
      ← "It focuses on: 1. compiling user goals before construction 2. separating truth
         work from expression work 3. exposing the active task 4. exposing blocked
         downstream work 5. preventing premature completion claims 6. verifying before
         unlock 7. making long AI workflows easier to inspect"
         (https://raw.githubusercontent.com/onestardao/WFGY/HEAD/README.md)
    the artifacts are text meant to be pasted into an assistant, not installed
      ← "You can download it, paste it into an AI assistant, agent rule file, workflow
         policy, or future skill implementation, and test it immediately."
         (https://raw.githubusercontent.com/onestardao/WFGY/HEAD/README.md)
    a prior generation ships as a single TXT file uploaded to a model
      ← "### 120s quickstart / 1. Download the TXT pack / 2. Upload it to a strong LLM /
         3. Type `run`, then `go`, and follow the built-in console"
