# dakra/ghostel

why-it-is    a fast, correct, featureful terminal INSIDE Emacs, beyond older Emacs terminals
how-it-is
  technology   Emacs Lisp + a native module binding libghostty-vt
  technicality prebuilt binary auto-downloads on first use (no toolchain/build); MELPA install; works across macOS/Linux/BSD/Android/Windows
leaves       Kitty keyboard + graphics protocols · true color · synchronized output · shell integration for bash/zsh/fish/nushell
flags        none
