# typedb/typedb
what-it-is   a strongly-typed database with its own query language TypeQL, unifying relational, document and graph models
why-it-is    each classical DB model has shortcomings; a type-system-first model to express complex, interconnected data safely
how-it-is
  technology   TypeQL — "declarative, functional, and strongly-typed"; schema of three root types (entities / relations / attributes) with inheritance + interfaces
  technicality TypeDB Cloud or self-hosted Community Edition; language drivers + a TypeDB Studio GUI
leaves       polymorphic queries · conceptual data modeling · type safety "at the same time" as flexibility
flags        marketing-hype — "next-gen", "groundbreaking query language", "we've reinvented the database for the modern programming era"
trust        slightly eroded — the typed model is substantive; the register oversells it; user weighs
#graph       knowledge/graph-data theme: atomspace (19) hypergraph DB — share-tag, not an evidenced edge
